# 🐉 Pokédex do Irmão

Esta Pokédex foi criada com muito carinho como um presente para o meu irmão mais novo. O objetivo é proporcionar uma experiência divertida e interativa para explorar os Pokémons da primeira geração!

## 🚀 Funcionalidades

-   **Lista de Pokémons**: Exibição dos primeiros 34 Pokémons com nomes e tipos totalmente traduzidos para o **Português**.
-   **Detalhes Interativos**: Ao clicar em um Pokémon, uma janela flutuante (modal) se abre mostrando:
    -   **Imagem em Alta Resolução**: Arte oficial do Pokémon.
    -   **Estatísticas Detalhadas**: Vida (HP), Ataque, Defesa, Velocidade, etc.
    -   **Habilidades e Ataques**: Lista das principais características de cada criatura.
    -   **Tags Coloridas**: Identificação visual rápida de cada tipo (Grama, Fogo, Água, etc.).
-   **Totalmente Responsivo**: O site funciona perfeitamente tanto no computador quanto no celular.

## 🛠️ Tecnologias Utilizadas

-   **HTML5**: Estrutura semântica da página.
-   **CSS3**: Estilização moderna com animações, efeitos de desfoque (blur) e design responsivo.
-   **JavaScript (ES6+)**: Lógica para captura de cliques, manipulação do DOM e integração com API.
-   **[PokéAPI](https://pokeapi.co/)**: Utilizada para buscar dados técnicos e imagens oficiais em tempo real.

## 📂 Estrutura do Projeto

-   `index.html`: O coração do site, contendo a lista e a estrutura do modal.
-   `style.css`: Toda a "mágica" visual e regras de responsividade.
-   `main.js`: A inteligência por trás do site, lidando com a busca de dados e interações.
